# Colors

The interface is **monochrome**. Neutrals carry the whole UI and black (`primary`) is the accent. Color is
never decoration: if something is colored, it means something (error, AI, brand).

Two layers:

1. **Roles** (below) are what you use. They say what a color is *for*, so the whole system can be re-themed
   (dark mode, sub-brands) without touching components.
2. **Primitives** are the raw palette the roles point at. Don't use them directly in product code.

## Roles

Use as Tailwind utilities: `bg-{role}`, `text-{role}`, `border-{role}`, e.g. `bg-card text-muted-foreground`.

export const ref = (t) => mono(`${t.value.replace(/var\(--(.+)\)/, '$1')} · ${resolve(t.value)}`);
export const dark = (name) => darkRoles.find((d) => d.name === name);

## Dark theme

Add `class="dark"` to `<html>` and every role switches. Components need no changes. In dark, surfaces get
**lighter as they rise** (page `#111111` → card `#1a1a1a` → popover `#262626`) and the accent inverts to
near-white. Use the toolbar's theme switch to preview any story in dark.

## Accessibility

All text roles meet **WCAG AA (4.5:1)** on the backgrounds they're used on. Light:

text. Use `muted-foreground`.
