# Brand accent

The brand gradient is the only color in the system. It's **reserved for AI and brand moments**: the AI avatar,
AI-generated highlights, and brand surfaces like onboarding or empty states.

<Unstyled>
	<div className="flex flex-wrap items-center gap-8 font-sans">
		<div className="bg-brand size-10 rounded-full blur-[2px]" />
		<div className="bg-brand h-24 w-64 rounded-xl" />
		<div className="flex gap-2">
			{primitives
				.filter((t) => t.name.startsWith('--brand'))
				.map((t) => (
					<div key={t.name} className="flex flex-col gap-1">
						<div className="size-12 rounded-sm" style={{ background: t.value }} />
						<code className="text-caption">{t.name.slice(2)}</code>
						<span className="text-caption text-muted-foreground">{t.value}</span>
					</div>
				))}
		</div>
	</div>
</Unstyled>

Use the `bg-brand` utility. Individual stops are available as `brand-1` … `brand-4`.

## Don’t

- Don’t use the gradient for buttons, links or status. Those stay monochrome or use `destructive`.
- Don’t put body text on the gradient.
- Don’t use more than one gradient element per view.
