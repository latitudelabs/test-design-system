# Typography

**Inter** only, in two weights: **Regular (400)** and **Medium (500)**. Hierarchy comes from size and color, not
from bold. Text at 16px and up is tracked **−2%**.

Each style is a Tailwind utility that sets size, line height, letter spacing and weight together:
`class="text-title"`. Combine with a color role, e.g. `text-caption text-muted-foreground`.

## Don’t

- Don’t use **bold (600+)**. Use Medium, size and color for emphasis.
- Don’t set sizes ad hoc (`text-[15px]`). If a size is missing, propose a new style.
- Don’t use `placeholder` grey for readable text. Secondary text is `text-muted-foreground`.
